 🏦 Smart Lender – ER Diagram Documentation

## 📌 Overview
The *Smart Lender* database is designed to manage loan applications and predict loan approval using Machine Learning. It stores user information, applicant details, credit history, loan applications, ML model details, and prediction results. The database structure ensures efficient data management, integrity, and accurate prediction.

---

## 👤 USER
*Purpose:* Stores the details of system users.

*Fields:*
- 🔹 User ID (Primary Key)
- 🔹 Name
- 🔹 Email
- 🔹 Role
- 🔹 Created At

---

## 🧑‍💼 APPLICANT_PROFILE
*Purpose:* Stores personal and demographic details of loan applicants.

*Fields:*
- 🔹 Applicant ID (Primary Key)
- 🔹 Gender
- 🔹 Marital Status
- 🔹 Education
- 🔹 Self Employed
- 🔹 Dependents
- 🔹 Property Area

---

## 💳 CREDIT_HISTORY
*Purpose:* Stores the applicant's credit information.

*Fields:*
- 🔹 Credit ID (Primary Key)
- 🔹 Applicant ID (Foreign Key)
- 🔹 Credit Score
- 🔹 Credit History Status

---

## 💰 LOAN_APPLICATION
*Purpose:* Stores loan application details.

*Fields:*
- 🔹 Loan ID (Primary Key)
- 🔹 Applicant ID (Foreign Key)
- 🔹 Income
- 🔹 Co-applicant Income
- 🔹 Loan Amount
- 🔹 Loan Term
- 🔹 Application Date

---

## 🤖 MODEL
*Purpose:* Stores Machine Learning model information.

*Fields:*
- 🔹 Model ID (Primary Key)
- 🔹 Model Name
- 🔹 Model Number
- 🔹 Algorithm
- 🔹 Training Accuracy
- 🔹 Testing Accuracy
- 🔹 File Path

---

## 📊 PREDICTION_RESULT
*Purpose:* Stores prediction results generated by the Machine Learning model.

*Fields:*
- 🔹 Prediction ID (Primary Key)
- 🔹 Loan ID (Foreign Key)
- 🔹 Model ID (Foreign Key)
- 🔹 Prediction Status
- 🔹 Probability Score
- 🔹 Prediction Time

---

# 🔗 Entity Relationships

- 👤 One *User* can manage multiple *Applicant Profiles*.
- 🧑‍💼 One *Applicant Profile* can have multiple *Credit History* records.
- 🧑‍💼 One *Applicant Profile* can submit multiple *Loan Applications*.
- 💳 Credit History supports the loan approval decision.
- 🤖 One *Machine Learning Model* can generate multiple *Prediction Results*.
- 📊 Each *Prediction Result* is linked to one *Loan Application* and one *Machine Learning Model*.

---

# ✅ Conclusion

The *Smart Lender ER Diagram* provides a structured database design for managing loan applications and Machine Learning predictions. It ensures data consistency
